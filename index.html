How to read housing debt

Financial assets excludes loans and is useful for judging liquidity. Financial assets less debt subtracts the mortgage, but this simulator does not currently add the home’s market value as an asset—so it is not complete household net worth after a purchase. A true household-net-worth figure would add home value and subtract the remaining mortgage.
